Retrofy

Classic Spotify. Modern playback. Legacy iOS.

About

Retrofy brings Spotify back to legacy iOS devices, with an interface inspired by the classic 2012 Spotify app.

Designed for iOS 6 and ARMv7 devices, Retrofy uses librespot to provide modern Spotify playback functionality on older hardware.

Using an older device?

If you're running iOS 4 or 5, or your device does not support ARMv7, install Retrofy4 instead.

Features

  • Full Spotify track playback with Premium, powered by librespot
  • AI DJ
  • Video clip playback
  • Lyrics
  • Spotify connect
  • Browse your playlists & Spotify generated playlists with artwork, Liked Songs and search
  • Now Playing with seeking, shuffle, repeat and automatic track progression
  • Like tracks and add them to playlists
  • Lock screen playback controls and Control Center integration where supported
  • Resume where you left off after relaunching

Requirements

  • iOS: 6.0 or later
  • Processor: ARMv7 (iPhone 3GS or compatible device)
  • Account: Spotify Premium for full tracks; otherwise, 30-second previews

Changelog

Version 2.7.1

  • Rebuilt the interface in Slint for iOS 6.
  • Added touch scrolling, album art in track lists, a Play button on playlists, and an account logout button.
  • Swipe the mini player left to skip or right to go back.
  • Fixed Spotify DJ stopping after its first set of tracks.
  • Includes the PlayPlay v5 fallback and supports ARMv7 and ARMv7s.

Version 1.0.0

  • Added PlayPlay v5 as a fallback when Spotify refuses the legacy audio key.
  • PlayPlay supports full-track playback and seeking. Retrofy still tries the legacy key first.

Version 0.0.6

  • Added Home with Liked Songs, Made For You, and Spotify-generated playlists.
  • Added Spotify DJ with on-screen commentary and synced lyrics in Now Playing.
  • Added looping Spotify Canvas clips in Now Playing when available.
  • Improved playlist loading by fetching track details in batches.

Version 0.0.5

  • Made Retrofy a full Spotify Connect device. Start or control playback from another Spotify app.
  • Moved queue, shuffle, repeat, and automatic track progression to Spotify Connect.
  • Added automatic reconnection when Spotify closes the session.

Version 0.0.4

  • Fixed Spotify bugs and removed the bundled Web API client ID.

Version 0.0.3

  • Added ARMv7 support alongside ARMv7s, bringing full-track playback to more iOS 6 devices.

Version 0.0.2

  • First Retrofy release on the Summers repository.
  • Added full-track Spotify playback through librespot on iOS 6 for ARMv7s devices.
  • Included playlists, search, Liked Songs, and a Now Playing screen with seeking, shuffle, and repeat.
