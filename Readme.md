# Summers Repo

Cydia repository for Retrofy and other legacy revivals, hosted with GitHub Pages at
<https://zoe-vb.github.io/>.

## Layout

- `Release`: the repo's name and description in Cydia
- `CydiaIcon.png`: the repo's icon in Cydia's Sources list
- `debs/`: the packages
- `Packages`, `Packages.gz`, `Packages.bz2`: the package index, generated by `UpdateRepo.sh`
- `depictions/<package id>/`: the page Cydia shows for a package (its control file's `Depiction:` field)
- `index.html`: the page with the "Add to Cydia" button

## Adding or updating a package

1. Give the package a `Depiction: https://zoe-vb.github.io/depictions/<package id>/` line in its
   `DEBIAN/control`, and bump `Version:` for an update.
2. Build it with gzip compression (older Cydia can't unpack xz) and root ownership:

   ```sh
   dpkg-deb --root-owner-group -Zgzip -b <package folder> debs/<package id>_<version>_iphoneos-arm.deb
   ```

3. Remove the package's old .deb from `debs/`, add a depiction page for a new package, then run:

   ```sh
   ./UpdateRepo.sh
   ```

4. Commit and push. GitHub Pages serves the update within a minute or two.

Needs `dpkg-deb` and `dpkg-scanpackages`, from `sudo port install dpkg` (MacPorts) or `brew install dpkg`.
